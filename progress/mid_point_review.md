## 시간표 조회

- `app/timetable/page.tsx`
  - 저장된 시간표와 기본 시간표를 카드 스택 형태로 조회한다.
  - 새 시간표 추가, 시간표 수정, 삭제, 중요 표시 기능을 제공한다.
  - 중요 표시된 시간표가 목록 앞쪽으로 정렬된다.

## 성신 강좌 DB/API

- `scripts/fetch-sungshin-courses.mjs`
  - 성신 수강신청 사이트의 강좌 API에서 실제 강좌 데이터를 수집한다.
  - 수집 범위는 2023년 1학기부터 2026년 여름 계절학기까지다.

- `lib/sungshin-course-db.ts`
  - 수집된 실제 강좌 데이터를 로컬 DB 형태로 저장했다.
  - 현재 총 15,316개 강좌가 포함되어 있다.

- `app/api/sungshin-courses/route.ts`
  - 웹사이트 실행 중에는 외부 사이트를 다시 크롤링하지 않고 로컬 DB에서 강좌를 조회한다.
  - 강좌명, 교수명, 학과명, 과목코드, 이수구분, 시간, 강의실 등으로 검색할 수 있다.
  - 검색어와 정확히 일치하는 결과가 없으면 해당 학기 전체 후보를 내려줘 사용 흐름이 막히지 않게 했다.

## 현재 확인된 이슈/남은 작업

- 공지 API/공지 페이지는 프로덕션 빌드의 page data 수집 단계에서 오류가 있어 원인 확인이 필요하다.
- 게시판/강의평은 현재 클라이언트 상태 기반이므로 새로고침 후 사용자 작성 데이터가 사라진다.
- Supabase 스키마 초안은 있으나 실제 인증/DB 연동은 아직 적용되지 않았다.
- 실제 강좌 DB 파일이 매우 크므로, 이후에는 JSON 분리, 학기별 chunk 분리, 서버 전용 로딩 방식 등을 검토할 필요가 있다.
- 현재 개발 서버는 중복 실행 시 라우트/CSS가 꼬일 수 있어 하나의 `next dev`만 유지해야 한다.
