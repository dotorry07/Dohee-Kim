# 새내기 ON 페이지별 중간점검

점검일: 2026-07-21

## 1. 전체 진행 요약

현재 MVP의 주요 화면은 대부분 구현되어 있으며, 홈, 로그인/회원가입, 대시보드, 시간표, 시간표 편집, 지도, 게시판, 강의평, 공지사항 화면까지 사용 흐름을 확인할 수 있는 상태다. 타입 체크는 `npm run typecheck` 기준 통과했다.

다만 데이터 저장 방식은 아직 혼재되어 있다. 로그인/회원가입과 시간표는 로컬 스토리지 기반이고, 게시판/강의평 작성 내용은 클라이언트 상태에만 남는다. Supabase 스키마와 클라이언트 초안은 있으나 실제 인증/DB 연동은 적용되지 않았다.

## 2. 페이지별 점검

### 2.1 홈 페이지

- 파일: `app/page.tsx`
- 상태: 완료에 가까움
- 구현된 내용
  - 서비스명, 주요 설명, 회원가입/대시보드 진입 버튼을 제공한다.
  - 중요 공지, 최근 게시글, 최근 강의평을 목 데이터에서 요약 표시한다.
  - 주요 기능으로 이동하는 첫 진입 화면 역할을 수행한다.
- 보완할 점
  - 로그인 상태에 따라 CTA를 회원가입/대시보드/시간표 등으로 다르게 보여주면 흐름이 더 자연스럽다.
  - 공지 데이터는 현재 홈에서 `lib/data.ts` 목 데이터를 직접 사용하므로, 공지 API와 데이터 출처를 통일할 필요가 있다.

### 2.2 로그인 페이지

- 파일: `app/auth/login/page.tsx`
- 상태: MVP 완료
- 구현된 내용
  - 이메일/비밀번호 입력 폼을 제공한다.
  - 시연 계정 기본값을 넣어 즉시 테스트할 수 있다.
  - 입력값 검증 후 `lib/auth/client.ts`의 로컬 세션을 생성하고 대시보드로 이동한다.
  - 로그인 실패와 검증 오류 메시지를 표시한다.
- 보완할 점
  - 현재 비밀번호는 길이 중심으로 검증되고, 실제 계정 DB와 대조하지 않는다.
  - Supabase Auth 연동 시 로그인 실패 케이스, 세션 만료, 리다이렉트 정책을 다시 정리해야 한다.

### 2.3 회원가입 페이지

- 파일: `app/auth/signup/page.tsx`
- 상태: MVP 완료
- 구현된 내용
  - 이메일, 비밀번호, 비밀번호 확인, 이름/닉네임, 학과, 학년 입력을 제공한다.
  - 학과와 학년은 선택 목록으로 구성되어 있다.
  - 입력 검증 후 로컬 사용자 정보를 저장하고 대시보드로 이동한다.
- 보완할 점
  - 실제 서비스 기준으로는 이메일 중복 검사, 비밀번호 저장, 사용자 프로필 저장이 필요하다.
  - 학과 목록과 학년 정책이 실제 학교 데이터와 계속 맞는지 관리 기준이 필요하다.

### 2.4 대시보드 페이지

- 파일: `app/dashboard/page.tsx`
- 상태: MVP 완료
- 구현된 내용
  - `AuthGuard`로 로그인 사용자만 접근 가능하게 구성했다.
  - 사용자 닉네임, 학과, 학년, 오늘 날짜를 표시한다.
  - 대표 시간표의 오늘 수업을 보여준다.
  - 상단 고정 공지, 최근 게시글, 최근 강의평을 카드 형태로 요약한다.
- 보완할 점
  - 현재 대표 시간표는 목 데이터의 `isSelected` 값을 기준으로만 판단한다.
  - 사용자가 만든 저장 시간표와 대표 시간표 지정 상태가 대시보드에 완전히 반영되도록 연결이 필요하다.
  - 오늘 수업이 없는 날의 빈 상태 문구를 더 구체화하면 좋다.

### 2.5 시간표 목록 페이지

- 파일: `app/timetable/page.tsx`
- 상태: 핵심 기능 구현 완료
- 구현된 내용
  - 로그인 사용자 전용 페이지로 구성했다.
  - 기본 시간표와 로컬 스토리지에 저장된 시간표를 함께 보여준다.
  - 카드 스택 UI로 시간표 목록을 탐색할 수 있다.
  - 드래그, 한 칸 이동 버튼, 맨 앞/맨 뒤 이동 버튼을 지원한다.
  - 새 시간표 추가 모달, 수정 이동, 삭제 확인 모달을 제공한다.
  - 중요 표시한 시간표를 목록 앞쪽으로 정렬한다.
  - 원격 녹화 강의는 일반 주간 그리드와 분리해 온라인 강의 영역으로 표시한다.
- 보완할 점
  - 삭제/중요 표시/저장 데이터가 로컬 스토리지에만 저장된다.
  - 목 데이터 시간표와 사용자 생성 시간표가 같은 목록에 섞이므로, 실제 서비스에서는 소유자 기준 필터링이 필요하다.
  - 대표 시간표 선택 기능과 대시보드 반영 흐름이 아직 완성되지 않았다.

### 2.6 시간표 추가/수정 페이지

- 파일: `app/timetable/edit/page.tsx`
- 상태: 핵심 기능 구현 완료, 데이터 연동 고도화 필요
- 구현된 내용
  - 시간표 제목, 연도, 학기를 설정할 수 있다.
  - 지원 범위는 `2023년 1학기`부터 `2026년 여름 계절학기`까지다.
  - 연도/학기 변경 시 확인 모달로 기존 검색어와 검색 결과 초기화를 안내한다.
  - 사용자 학과/학년 기준 필수 이수 강의를 선택할 수 있다.
  - 실제 성신 수강신청 강좌 DB 기반 검색과 강좌 추가를 제공한다.
  - 강의 시간 겹침을 검사한다.
  - 원격 녹화 강의는 일반 겹침 검사와 분리한다.
  - 개인 일정은 시간표 그리드 드래그로 추가할 수 있다.
  - 개인 일정 생성/삭제는 앱 내부 모달로 처리한다.
  - 작성 중인 draft가 로컬 스토리지에 유지되어 다른 페이지 이동 후 돌아와도 복구된다.
- 보완할 점
  - 저장 결과가 로컬 스토리지에만 남으므로 계정 간 동기화가 되지 않는다.
  - 실제 강좌 DB가 코드 파일에 크게 포함되어 있어 번들/빌드 성능 점검이 필요하다.
  - 강좌 검색 결과가 많을 때의 페이징, 정렬, 학과 필터가 더 정교해질 필요가 있다.
  - 추천 시간표 생성 로직은 구현되어 있으나, 사용자에게 추천 기준과 결과 선택 흐름을 더 명확히 보여줄 필요가 있다.

### 2.7 지도 페이지

- 파일: `app/map/page.tsx`
- 상태: MVP 완료
- 구현된 내용
  - 정적 캠퍼스 지도 영역 위에 선택 장소 핀을 표시한다.
  - 건물명, 장소명, 설명, 태그 기반 검색을 지원한다.
  - 강의동, 도서관, 학생회관, 식당/카페, 행정실, 편의시설 카테고리 필터를 제공한다.
  - 시간표에서 `building` query로 진입하면 해당 건물을 초기 검색/선택 상태로 사용한다.
  - 선택된 장소의 설명, 건물명, 층, 태그를 표시한다.
- 보완할 점
  - 현재 지도는 정적 약도 기반이므로 실제 길찾기나 현재 위치 기능은 없다.
  - 강의실 단위 검색 정확도는 장소 데이터 품질에 따라 제한된다.
  - 모바일에서 지도와 검색 패널의 우선순위를 실제 사용 흐름 기준으로 다시 확인하면 좋다.

### 2.8 게시판 페이지

- 파일: `app/board/page.tsx`
- 상태: 화면 기능 구현, 영속화 미완료
- 구현된 내용
  - 새내기 Q&A, 자유게시판, 학과별, 정보 공유 카테고리를 제공한다.
  - 제목/내용 검색과 카테고리 필터를 지원한다.
  - 글 목록, 글 상세, 댓글 목록을 한 페이지에서 확인할 수 있다.
  - 로그인 사용자는 글과 댓글을 작성할 수 있다.
  - 본인이 작성한 글에는 삭제 버튼이 표시된다.
- 보완할 점
  - 작성한 글과 댓글은 React 상태에만 저장되어 새로고침하면 사라진다.
  - `app/api/posts/route.ts`는 존재하지만 현재 페이지는 해당 API를 사용하지 않는다.
  - 글 수정, 댓글 삭제, 상세 URL 분리, 조회수 증가, 권한 검증은 추가 구현이 필요하다.

### 2.9 강의평 페이지

- 파일: `app/reviews/page.tsx`
- 상태: 화면 기능 구현, 영속화 미완료
- 구현된 내용
  - 로그인 사용자 전용 페이지로 구성했다.
  - 강의명 또는 교수명 검색을 지원한다.
  - 강의별 평균 평점, 학기, 과제량, 시험 난이도, 출석 방식, 자유 후기를 표시한다.
  - 로그인 사용자는 강의평을 작성할 수 있다.
  - 같은 사용자가 같은 강의명/교수명 조합으로 중복 작성하지 못하게 검사한다.
- 보완할 점
  - 새 강의평은 클라이언트 상태에만 저장되어 새로고침 후 사라진다.
  - `app/api/reviews/route.ts`는 존재하지만 현재 페이지는 해당 API를 사용하지 않는다.
  - 학기 입력이 자유 텍스트라 시간표의 학기 선택 방식과 통일하면 좋다.
  - 욕설/개인정보 신고 같은 운영 정책은 아직 화면과 데이터에 반영되지 않았다.

### 2.10 공지사항 페이지

- 파일: `app/notices/page.tsx`
- 상태: 화면 구현 완료, API 안정성 점검 필요
- 구현된 내용
  - 공지 제목/요약 검색과 카테고리 필터를 제공한다.
  - API(`/api/notices`)에서 공지 데이터를 불러온다.
  - 중요 공지와 일반 공지를 분리해 표시한다.
  - 이미지가 있는 공지는 썸네일을 표시한다.
  - 신청 링크, 신청 마감일, 신청기간 마감 상태를 표시한다.
  - 마감된 공지는 별도 스타일과 배지로 구분한다.
- 보완할 점
  - `app/api/notices/route.ts`가 성신 홈페이지를 런타임에 스크래핑하므로 네트워크 실패나 사이트 구조 변경에 취약하다.
  - 이전 점검 기준 프로덕션 빌드의 page data 수집 단계 오류가 언급되어 있어 재현과 원인 확인이 필요하다.
  - 홈/대시보드의 공지 데이터는 목 데이터를 직접 사용하고, 공지 페이지는 API를 사용하므로 데이터 출처 통일이 필요하다.

## 3. 공통 구성 점검

### 3.1 레이아웃과 헤더

- 파일: `app/layout.tsx`, `components/AppHeader.tsx`, `app/globals.css`
- 상태: MVP 완료
- 구현된 내용
  - 전역 레이아웃과 상단 내비게이션을 구성했다.
  - 대시보드, 시간표, 지도, 게시판, 강의평, 공지 메뉴를 제공한다.
  - 브라우저 탭 아이콘은 `public/images/app-logo.png`를 사용한다.
  - 내부 헤더 로고는 `public/images/app-logo-header.png`를 사용한다.
  - 로그인 상태에 따라 로그인 링크 또는 로그아웃 버튼을 보여준다.
- 보완할 점
  - 현재 로그인 상태 변경 후 헤더 반영 방식은 클라이언트 로컬 스토리지에 의존한다.
  - 실제 인증 도입 시 서버/클라이언트 렌더링 간 세션 표시 정책을 정리해야 한다.

### 3.2 인증 보호

- 파일: `components/AuthGuard.tsx`, `lib/auth/client.ts`
- 상태: MVP 완료
- 구현된 내용
  - 로컬 스토리지 기반 세션으로 로그인 여부를 판별한다.
  - 인증이 필요한 페이지는 미로그인 시 로그인 페이지로 이동한다.
- 보완할 점
  - 보안상 실제 인증이 아니므로 Supabase Auth 또는 별도 백엔드 인증으로 교체해야 한다.
  - 서버 API 레벨 권한 검증은 아직 적용되지 않았다.

### 3.3 데이터/API

- 파일: `lib/data.ts`, `lib/types.ts`, `lib/timetable.ts`, `app/api/*`
- 상태: MVP 데이터 기반 구성 완료
- 구현된 내용
  - 사용자, 시간표, 장소, 게시글, 강의평, 공지 목 데이터를 제공한다.
  - 타입 정의와 시간표 유틸 로직이 분리되어 있다.
  - 게시판, 강의평, 공지, 장소, 시간표 추천, 성신 강좌 검색 API route가 있다.
  - 성신 강좌 DB는 로컬 데이터로 포함되어 실행 중 외부 크롤링 없이 검색할 수 있다.
- 보완할 점
  - 페이지가 API를 쓰는 부분과 직접 목 데이터를 쓰는 부분이 섞여 있다.
  - 게시판/강의평 API는 응답 생성 수준이고 실제 DB 저장은 하지 않는다.
  - Supabase migration 초안은 있으나 앱 로직과 연결되지 않았다.

## 4. 우선순위별 남은 작업

### 4.1 1순위

- Supabase Auth와 사용자 프로필 저장을 실제 로그인/회원가입에 연결한다.
- 시간표 저장, 대표 시간표 선택, 삭제, 중요 표시를 DB에 저장한다.
- 게시판 글/댓글 작성과 강의평 작성을 API 및 DB 기반으로 전환한다.
- 공지 API의 프로덕션 빌드/런타임 오류를 재현하고 수정한다.

### 4.2 2순위

- 홈, 대시보드, 공지 페이지의 공지 데이터 출처를 통일한다.
- 시간표 목록의 대표 시간표 선택 기능을 명확히 추가한다.
- 시간표 편집 페이지의 강좌 검색 필터와 결과 표시를 개선한다.
- 게시글 상세 URL, 글 수정, 댓글 삭제, 조회수 처리를 추가한다.

### 4.3 3순위

- 지도 데이터를 보강하고 강의실 단위 검색 정확도를 높인다.
- 강의평의 학기 입력을 선택형으로 바꾸고 시간표 학기 체계와 맞춘다.
- 신고/관리자 기능, 부적절한 콘텐츠 처리 정책을 추가한다.
- 성신 강좌 DB를 학기별 파일 또는 서버 전용 데이터로 분리해 빌드 부담을 줄인다.
